---
title: Installation
description: Put RexPlayerWarps on a Paper, Purpur, or Folia server.
sidebar:
  order: 1
---

1. Download the jar.
2. Put it in the server `plugins/` folder.
3. Start the server once so `plugins/RexPlayerWarps/config.yml` and `categories.yml` are written.
4. Edit `config.yml`. Add categories in `categories.yml` if the defaults are not enough.
5. Give players a limit node such as `rexplayerwarps.warps.3`.
6. Run `/rexplayerwarps reload`, or restart.

Vault is not required for free warps. Paid warps need a Vault economy, or `economy.mode: command` with PlaceholderAPI for the balance placeholder.

PlaceholderAPI is not required. If it is installed when RexPlayerWarps enables, the `%rexplayerwarps_...%` placeholders register on their own.
